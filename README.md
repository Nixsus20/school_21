# School 21 — C и SQL

Здесь лежат мои учебные реализации на C и решения задач на PostgreSQL. Среди них — собственные версии `cat` и `grep`, библиотеки для работы со строками, десятичными числами и матрицами, терминальный Tetris и SQL-запросы разной сложности. Часть проектов делалась в команде.

## Скачать и проверить

Нужны **Git, Make и Docker**. На Linux Docker должен быть запущен, а у пользователя — доступ к его daemon.

```bash
git clone https://github.com/Nixsus20/school_21.git
cd school_21
make check
```

Эта команда сама собирает проверочное Docker-окружение и запускает тесты. Устанавливать локально GCC, Check, ncurses и PostgreSQL для этого не требуется. При первом запуске Docker скачает базовый образ и необходимые пакеты.

Что именно проверяется:

1. Сборка `s21_cat`, `s21_grep`, трёх статических библиотек и терминального Tetris.
2. Сравнение вывода `cat` и `grep` с системными утилитами на небольшом наборе входных данных.
3. Unit-тесты библиотек и Tetris через **Check**.
4. Выполнение SQL-скриптов на **PostgreSQL**. Для каждой серии создаётся отдельная временная база с тестовыми данными, которая удаляется после проверки.

В терминале для каждого шага выводится `PASS`, `FAIL` или `SKIP`. При ошибке показывается фрагмент журнала. Ненулевой код завершения означает, что какая-то проверка не прошла.

**Важно:** SQL-проверка использует специально созданный [небольшой набор данных](scripts/sql-fixture.sql), а не исходную базу Школы 21. Это проверка возможности выполнить запросы на совместимой схеме, а не сверка всех ответов с эталоном. Тесты на Check тоже не заменяют ручную проверку граничных случаев.

### Без Docker

Если `gcc`, `make` и нужные библиотеки уже установлены:

```bash
make check-local
```

Этот вариант собирает C-проекты во временной папке, запускает доступные тесты и не требует PostgreSQL. Проверки SQL будут отмечены как `SKIP`. Для полного прогона используйте `make check`.

| Проект | Что проверять |

| [Simple Bash Utils](C/simple-bash-utils/) | Аргументы командной строки, флаги и вывод `cat`/`grep` |

В каждой папке есть отдельный README с требованиями задания, ограничениями и командами сборки. Исходники находятся в `src/`.

### Запустить Tetris самому

Для интерактивной игры нужна локально установленная библиотека разработки **ncurses**, GCC и Make:

```bash
make -C C/terminal-tetris/src
./C/terminal-tetris/src/tetris
```

Управление: `s` — старт, стрелки — перемещение, пробел — поворот, `p` — пауза, `Esc` — выход. Для нормального отображения нужен терминал достаточного размера.

## Как устроена проверка

- [`Makefile`](Makefile) — команды `check` и `check-local`.
- [`scripts/check.sh`](scripts/check.sh) — сборка, тесты, сравнение вывода и запуск SQL.
- [`scripts/sql-fixture.sql`](scripts/sql-fixture.sql) — независимая тестовая схема с демонстрационными данными.
- [`Dockerfile`](Dockerfile) — воспроизводимое окружение с GCC, Check, ncurses и PostgreSQL.
- [GitHub Actions](.github/workflows/verify.yml) — такая же проверка при изменениях в репозитории.

Командная работа отмечена в описаниях соответствующих проектов. Все файлы задания пересказаны кратко: школьные методички в публичную копию не переносились.

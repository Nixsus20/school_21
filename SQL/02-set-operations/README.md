# SQL 02. Множества и JOIN

Здесь основная тема — как собирать данные из нескольких выборок. Причём важно не только получить нужные строки, но и понимать, **сохраняет ли операция повторяющиеся записи**.

## Задания

| Файл | Что требовалось |

| [ex01](src/ex01/day01_ex01.sql) | Объединить имена людей и названия пицц, но сохранить повторения и нужный порядок групп. |

## В чём были ограничения

В ex02 специально запрещались обычные способы удаления дублей (`DISTINCT`, группировка и `JOIN`). Для ex03 и ex04 нужно было обойтись без соединений; задача решалась операциями над множествами. В ex08 допускался именно `NATURAL JOIN`.

Для разности с сохранением повторов важен вариант `ALL`. Это не то же самое, что обычное удаление уникальных строк.

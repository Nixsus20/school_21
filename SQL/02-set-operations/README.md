# Set operations

Объединение результатов нескольких запросов.

## Задача
Использовать UNION и другие операции комбинирования выборок, сортировку и работу с повторяющимися данными.

## Что сделано
- 11 SQL-файлов в src/ex00–ex10.
- Запросы, объединяющие выборки из разных таблиц.

## Как посмотреть
Запросы находятся в [`src/`](src/) и рассчитаны на PostgreSQL и учебную схему. Каждый файл можно выполнять отдельно после подготовки таблиц.

Учебная работа School 21. Условия заданий пересказаны своими словами.

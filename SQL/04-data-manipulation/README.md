# SQL 04. Запросы и изменение данных

В этой серии сначала нужно было разобрать связи между посещениями и заказами, а потом поработать с данными напрямую: `INSERT`, `UPDATE`, `DELETE`. Вторая половина упражнений меняет содержимое базы, поэтому порядок запуска важен.

## Задания

| Файл | Что нужно было сделать |
| --- | --- |
| [ex00](src/ex00/day03_ex00.sql) | Найти пиццы в ценовом диапазоне 800–1000 для посещений Кейт; вывести цену, пиццерию и дату. |
| [ex01](src/ex01/day03_ex01.sql) | Найти позиции меню, которые никто не заказывал. |

## Ограничения

- **ex03–ex04:** нужно было аккуратно работать с кратностью записей. `ALL` и операции без `ALL` дают разный результат.
- **ex08–ex10:** вместо жёстко зашитых ID нужно получать идентификаторы из БД запросом.
- **ex12:** требовалось `INSERT INTO ... SELECT`, а не серия отдельных вставок. `ROW_NUMBER()` и фиксированные ID запрещались.
- **ex07–ex13:** изменения накапливаются. Следующее упражнение может зависеть от записей, созданных предыдущим.

## Проверка

Файлы в `src/exNN` рассчитаны на PostgreSQL и исходную учебную БД. В пустой базе они не выполнятся. Для экспериментов лучше использовать отдельную тестовую копию данных: часть скриптов записывает и удаляет строки.

Отдельной автоматической проверки результатов в этом репозитории нет.

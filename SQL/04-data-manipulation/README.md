# Data manipulation (DML)

Запросы для чтения и изменения данных.

## Задача
Практиковаться в DML, выборках из связанных таблиц и изменении записей.

## Что сделано
- SQL-файлы отдельных упражнений в src/ex00–ex13.
- Запросы к таблицам people, visits, pizzerias и menu.

## Как посмотреть
Запросы находятся в [`src/`](src/) и рассчитаны на PostgreSQL и учебную схему. Каждый файл можно выполнять отдельно после подготовки таблиц.

Учебная работа School 21. Условия заданий пересказаны своими словами.

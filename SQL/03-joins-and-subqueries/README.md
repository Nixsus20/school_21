# Joins and subqueries

Запросы к связанным таблицам.

## Задача
Получать связанные данные через JOIN и подзапросы, находить отсутствующие и совпадающие записи.

## Что сделано
- 11 SQL-файлов в src/ex00–ex10.
- Примеры с LEFT JOIN и фильтрацией по связанным данным.

## Как посмотреть
Запросы находятся в [`src/`](src/) и рассчитаны на PostgreSQL и учебную схему. Каждый файл можно выполнять отдельно после подготовки таблиц.

Учебная работа School 21. Условия заданий пересказаны своими словами.

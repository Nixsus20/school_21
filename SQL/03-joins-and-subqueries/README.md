# SQL 03. JOIN, пропуски в данных, CTE

Третий набор упражнений — работа со связанными таблицами. Сначала нужно было научиться находить отсутствующие записи через соединения, потом собирать более сложные запросы по посетителям, заказам и меню пиццерий.

## Задания

| Файл | Условие |

| [ex00](src/ex00/day02_ex00.sql) | Найти пиццерии, куда никто не приходил. |
| [ex01](src/ex01/day02_ex01.sql) | Найти отсутствующие даты посещений с 1 по 10 января для двух заданных посетителей. |
| [ex02](src/ex02/day02_ex02.sql) | Показать все сочетания посетителей и пиццерий за период, включая отсутствующие связи; заменить `NULL` на дефис. |

## Условия и ограничения

Для **ex00–ex03** задача намеренно была ограничена: нельзя было использовать `IN`, `NOT IN`, `EXISTS`, `NOT EXISTS`, а также `UNION`, `EXCEPT`, `INTERSECT`. Требовалось разобраться с `LEFT / RIGHT / FULL JOIN` и анализом пустых связей.

В ex03 дополнительно требовалось вынести генерацию дат в CTE. В остальных упражнениях ключевой момент — корректные связи между таблицами, условия фильтрации, ожидаемые названия колонок и сортировка.

## Файлы

Решения находятся в `src/ex00`–`src/ex10` и написаны для PostgreSQL. Нужна заполненная учебная схема; в этом репозитории находятся запросы без исходной базы.

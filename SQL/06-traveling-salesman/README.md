# SQL 06. Traveling salesman problem

Задача на поиск маршрутов в графе через SQL. Есть четыре вершины (`a`, `b`, `c`, `d`) и стоимости переходов между ними. Нужно обойти все вершины, вернуться в `a` и посчитать цену пути.

## Условия задачи

1. Создать таблицу `nodes(point1, point2, cost)` со стоимостью каждого перехода в обе стороны.
2. Найти все маршруты минимальной стоимости, которые начинаются и заканчиваются в `a` и проходят остальные вершины по одному разу.
3. Во второй части показать также маршруты максимальной стоимости.
4. Вернуть стоимость маршрута и запись самого маршрута; сортировка сначала по стоимости, затем по маршруту.

Использовался PostgreSQL. Готовой процедуры обхода графа не было: путь строился SQL-запросом с рекурсией.

## Что в файлах

- [`team00_ex00.sql`](src/team00_ex00.sql) — создание `nodes`, заполнение рёбер, `WITH RECURSIVE` и отбор наиболее дешёвых маршрутов.
- [`team00_ex01.sql`](src/team00_ex01.sql) — ещё один рекурсивный запрос по графу.

Рекурсивный CTE последовательно дописывает вершины к маршруту и накапливает стоимость рёбер. Условие исключает повторный проход по уже посещённым городам, после чего добавляется возвращение в начальную точку.

## Запуск

Нужен PostgreSQL. Сначала выполняется `team00_ex00.sql` (он создаёт таблицу с данными); затем можно выполнить `team00_ex01.sql` в той же БД.

# Traveling salesman (SQL)

Поиск оптимального маршрута через рекурсивный SQL-запрос.

## Задача
Представить граф таблицей переходов и найти маршрут минимальной стоимости при обходе заданных вершин.

## Что сделано
- src/team00_ex00.sql — граф и поиск минимума.
- src/team00_ex01.sql — дополнительный вариант запроса.

## Как посмотреть
Запросы находятся в [`src/`](src/) и рассчитаны на PostgreSQL и учебную схему. Каждый файл можно выполнять отдельно после подготовки таблиц.

Учебная работа School 21. Условия заданий пересказаны своими словами.

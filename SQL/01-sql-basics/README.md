# SQL 01. SELECT, фильтрация, сортировка

Первый набор упражнений с таблицами `person`, `pizzeria`, `menu`, `person_visits` и `person_order`. Здесь запросы ещё короткие, но часть заданий специально ограничивала допустимый синтаксис: результат нужно было получить определённым способом.

## Задачи

| Файл | Условие |
| --- | --- |
| [ex00](src/ex00/day00_ex00.sql) | Вывести имя и возраст жителей Казани. |
| [ex01](src/ex01/day00_ex01.sql) | Отобрать женщин из Казани, отсортировать по имени. |
| [ex02](src/ex02/day00_ex02.sql) | Найти пиццерии с рейтингом от 3.5 до 5 двумя запросами: сначала сравнениями `>=` / `<=`, затем через `BETWEEN`. |
| [ex03](src/ex03/day00_ex03.sql) | Получить уникальные ID посетителей за заданный период или посетителей определённой пиццерии; сортировка по ID в обратном порядке. |
| [ex04](src/ex04/day00_ex04.sql) | Собрать строку из имени, возраста, пола и города проживания; отсортировать по рассчитанному значению. |
| [ex05](src/ex05/day00_ex05.sql) | Найти имена людей, заказавших определённые позиции меню в конкретную дату. Имя получать вложенным запросом прямо в `SELECT`. |
| [ex06](src/ex06/day00_ex06.sql) | Дополнить прошлый запрос вычисляемым логическим полем с проверкой имени через `CASE`. |
| [ex07](src/ex07/day00_ex07.sql) | Разбить людей на три возрастных интервала с помощью `CASE` и отсортировать по вычисленной категории. |
| [ex08](src/ex08/day00_ex08.sql) | Выбрать заказы с чётными ID из `person_order`. |
| [ex09](src/ex09/day00_ex09.sql) | Показать имена посетителей и названия пиццерий за период, используя вложенный запрос в `FROM` и скалярные подзапросы в `SELECT`. |

## Ограничения

- Для упражнений использовался ANSI SQL и заданная учебная схема.
- В **ex05–ex06** нельзя было использовать `IN` и любые `JOIN` — это задания именно на скалярные подзапросы.
- В **ex09** также запрещались `JOIN`: требовалось собрать результат через подзапросы.
- В некоторых заданиях важны точные имена столбцов, порядок сортировки и сохранение либо исключение дублей.

## Как смотреть решения

Каждое упражнение — отдельный файл `src/exNN/day00_exNN.sql`. Для выполнения нужна PostgreSQL-база с учебными таблицами и исходными данными. Схема и набор данных здесь не опубликованы, поэтому запускать всё подряд в пустой БД не получится.

Файлы показывают написанные запросы; соответствие каждого результата эталонным данным отдельно не перепроверялось.

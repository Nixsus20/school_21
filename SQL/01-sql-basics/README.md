# SQL basics

Простые выборки из учебной базы данных.

## Задача
Составить SELECT-запросы с фильтрацией, сортировкой и условиями для отдельных таблиц.

## Что сделано
- 10 отдельных SQL-файлов в src/ex00–ex09.
- Запросы по данным людей, меню и пиццерий.

## Как посмотреть
Запросы находятся в [`src/`](src/) и рассчитаны на PostgreSQL и учебную схему. Каждый файл можно выполнять отдельно после подготовки таблиц.

Учебная работа School 21. Условия заданий пересказаны своими словами.

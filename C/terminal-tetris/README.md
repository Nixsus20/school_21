# Terminal Tetris

Консольный тетрис на C с интерфейсом на ncurses.

## Задача
Написать игровую механику: генерация фигур, перемещение, поворот, столкновения, удаление заполненных линий и подсчёт очков. Игровую логику отделить от интерфейса.

## Реализация
- Логика состояний игры и игровое поле.
- Генерация и поворот фигур, управление с клавиатуры.
- Терминальный интерфейс и исходники тестов.

Исходники — в [`src/`](src/).

## Сборка и тесты
```bash
cd src
make
make run
# тесты: make test
```

Тесты входят в проект, но результат их запуска для этой версии не проверялся.

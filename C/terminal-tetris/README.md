# Terminal Tetris / BrickGame v1.0

Тетрис для терминала, написанный на C с использованием `ncurses`. По заданию игровой движок и вывод на экран должны были быть отдельными частями, а переходы между состояниями игры — описываться конечным автоматом.

## Что требовалось сделать

- Поле **10 × 20** клеток и все семь стандартных фигур.
- Запуск, пауза, завершение, перемещение влево/вправо, ускорение падения и поворот.
- Проверка столкновений, фиксация фигуры, удаление заполненных рядов, конец игры при заполнении верхней части поля.
- Предпросмотр следующей фигуры.
- Отдельная логика в `src/brick_game/tetris/` и терминальный интерфейс в `src/gui/cli/`.

Дополнительные пункты задания — счёт с начислением очков за 1–4 линии, сохранение рекорда между запусками и уровни сложности. Уровень должен повышаться с набором очков, ускоряя падение фигур; верхняя граница — 10.

Технические условия: C11, `gcc`, `ncurses`, модель игры через конечный автомат, Makefile с целями сборки/установки/очистки/тестирования. Также требовались диаграмма автомата и тесты на Check с покрытием игровой логики от 80%.

## Что видно в коде

- [`brick_game/tetris/`](src/brick_game/tetris/) — состояния, управление полем и фигурами, движение и вращение.
- [`gui/cli/`](src/gui/cli/) — вывод в терминал.
- [`src/Makefile`](src/Makefile) — сборка, запуск и команды установки.
- [`src/test.c`](src/test.c) — тесты.

В игровой логике есть счёт, запись рекорда в `max_score.txt`, увеличение уровня после каждых 600 очков и ограничение в 10 уровней. Диаграмма конечного автомата в опубликованных файлах не найдена, а цель `dvi` в Makefile оставлена заглушкой.

## Как запустить

Потребуются `gcc`, `make` и библиотека `ncurses`.

```sh
cd src
make
make run
```

Для тестов нужна Check (на Linux также используются `pthread` и `subunit`):

```sh
make test
# HTML-отчёт: make gcov_report
```

Наличие тестов не означает, что их текущий результат и покрытие уже подтверждены.

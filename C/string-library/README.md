# s21_stringplus

Реализация строковых и memory-функций стандартной библиотеки C.

## Задача
Написать собственные аналоги функций string.h и часть функций форматированного вывода, разобраться с указателями, памятью и обработкой строк.

## Реализация
- Копирование, сравнение и поиск в строках и памяти.
- Изменение строк и реализация s21_sprintf.
- Библиотека в виде архива .a, Makefile и тесты.

Исходники — в [`src/`](src/).

## Сборка и тесты
```bash
cd src
make
make test
```

Тесты входят в проект, но результат их запуска для этой версии не проверялся.

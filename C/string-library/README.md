# s21_stringplus

Реализация строковых функций на C. В обычной программе эти операции скрываются за `string.h`; здесь нужно было написать их самостоятельно и разобраться с указателями, нуль-терминированными строками и передачей памяти.

## Что требовалось

Написать собственные аналоги функций `string.h`: поиск, сравнение, копирование, работа с памятью и строковыми фрагментами. Ещё одна часть — свой `sprintf` с поддержкой базовых спецификаторов (символ, строка, целые и вещественные числа), ширины и точности.

Ограничения задания:
- C11 и `gcc`, код в `src/`, функции с префиксом `s21_`.
- Результат — статическая библиотека `s21_string.a` и заголовок `s21_string.h`.
- Нельзя подменять собственную реализацию вызовами соответствующих стандартных строковых функций. Системную библиотеку разрешалось использовать для сравнения в тестах.
- Работа с однобайтовыми строками ASCII; сообщения системных ошибок для `strerror` следовало хранить самостоятельно.
- Тесты на Check со сравнением со стандартными функциями. Требование по покрытию — от 80% для каждой функции; отчёт через `gcov/lcov`.

В задании были и бонусные задачи: дополнительные форматы `sprintf`, `sscanf` и несколько вспомогательных строковых функций. Это не значит, что все бонусы выполнены в текущем коде.

## Реализация в этом репозитории

Исходники распределены по назначению:
- [`copying_functions/`](src/copying_functions/) и [`compare_functions/`](src/compare_functions/) — копирование и сравнение.
- [`search_functions/`](src/search_functions/) и [`calculation_functions/`](src/calculation_functions/) — поиск и вычисление параметров строк.
- [`sprintf/`](src/sprintf/) — собственная версия форматированного вывода.
- [`src/tests.c`](src/tests.c) — тестовый код.

Также есть `s21_strerror`, `s21_strtok`, `s21_trim`, перевод регистра и другие функции. Реализации `sscanf` в этой версии нет.

## Сборка и тестирование

Понадобятся `gcc`, `make` и библиотека Check. Для отчёта о покрытии также нужны `lcov` и `genhtml`.

```sh
cd src
make                 # s21_string.a
make test
make gcov_report
make clean
```

Тесты и цель для отчёта присутствуют, но фактические результаты и процент покрытия для опубликованной версии отдельно не проверялись.

Командный учебный проект Школы 21.

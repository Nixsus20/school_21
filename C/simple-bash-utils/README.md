# Simple Bash Utils

Две небольшие программы на C, повторяющие основные возможности `cat` и `grep`. Задача была в том, чтобы разобраться с аргументами командной строки, чтением файлов и регулярными выражениями, а затем сравнить поведение своих утилит с системными.

## Условия задания

**cat:** выводить файлы с поддержкой `-b`, `-e` / `-E`, `-n`, `-s`, `-t` / `-T`. По смыслу это нумерация строк, отображение непечатаемых символов и сжатие последовательностей пустых строк. Для ряда флагов требовались и длинные GNU-имена.

**grep:** искать строки по шаблону. Обязательная часть включала `-e`, `-i`, `-v`, `-c`, `-l`, `-n`. Дополнительная — `-h`, `-s`, `-f`, `-o` и сочетания флагов.

Общие рамки:
- C11, `gcc`, структурный код; ориентир на POSIX.1-2017.
- Две отдельные исполняемые программы — `s21_cat` и `s21_grep`, каждая со своим Makefile.
- Для поиска разрешалось использовать библиотеки регулярных выражений.
- Проверка через сравнение результатов с обычными Unix-утилитами на разных аргументах и входных файлах.
- Поддержка чтения из stdin в задании не требовалась. Формулировка сообщений об ошибках могла отличаться от оригинала.

## Что лежит в коде

- [`src/cat/`](src/cat/) — разбор опций через `getopt_long`, чтение файлов, обработка строк и специальных символов.
- [`src/grep/`](src/grep/) — разбор параметров поиска, работа с шаблонами и обработка файлов.
- `test_s21_cat.sh` и `test_grep.sh` — сценарии для сравнения с системными командами.

## Сборка

Нужны `gcc` и `make`. Из корня проекта:

```sh
cd src/cat
make
./s21_cat -n some_file.txt
make test

cd ../grep
make
./s21_grep -n "pattern" some_file.txt
make test
```

`some_file.txt` здесь — пример имени файла, его нужно заменить своим.

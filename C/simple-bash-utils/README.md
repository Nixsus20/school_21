# Simple Bash Utils

Свои версии cat и grep на C.

## Задача
Сделать две консольные утилиты для вывода файлов и поиска строк по шаблону. Поддержать аргументы командной строки и основные флаги, сравнить поведение с системными командами.

## Реализация
- s21_cat — вывод содержимого файлов и обработка флагов.
- s21_grep — поиск по регулярным выражениям.
- Отдельные Makefile и shell-тесты для обеих утилит.

Исходники — в [`src/`](src/).

## Сборка и тесты
```bash
cd src/cat && make && make test
cd ../grep && make && make test
```

Тесты входят в проект, но результат их запуска для этой версии не проверялся.

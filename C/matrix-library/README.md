# s21_matrix

Небольшая библиотека линейной алгебры на C. Здесь всё завязано на динамической памяти: матрицу нужно создать, проверить, выполнить операцию и корректно освободить.

## Задание

Реализовать структуру `matrix_t` и основные операции с прямоугольными и квадратными матрицами:

| Группа | Функции |
| --- | --- |
| Память | `s21_create_matrix`, `s21_remove_matrix` |
| Арифметика | сумма, разность, умножение матриц и умножение на число |
| Проверки | сравнение матриц |
| Линейная алгебра | транспонирование, определитель, дополнения, обратная матрица |

Условия: C11, `gcc`, статическая библиотека `s21_matrix.a`, общий заголовок `s21_matrix.h`. Для сравнения дробных результатов допускалась погрешность в пределах шести знаков после запятой.

Как и в других C-заданиях школы, требовались тесты на Check и отчёт о покрытии; минимальная планка по условию составляла 80% на функцию. Это требование к работе, а не подтверждённый показатель текущего репозитория.

## В исходниках

Все функции лежат в отдельных файлах в [`src/`](src/). Например, `s21_determinant.c` вычисляет определитель, `s21_inverse_matrix.c` отвечает за обращение, `s21_create_matrix.c` и `s21_remove_matrix.c` — за управление памятью.

Тесты: [`src/tests/test.c`](src/tests/test.c).

## Сборка

```sh
cd src
make             # s21_matrix.a
make test
make gcov_report
```

Для тестов понадобится Check; для отчёта — `lcov` и `genhtml`. Отдельно не подтверждал, что все проверки проходят на текущем окружении.

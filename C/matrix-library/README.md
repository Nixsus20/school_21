# s21_matrix

Библиотека для работы с матрицами на C.

## Задача
Сделать создание и освобождение матриц, арифметические операции, транспонирование, вычисление определителя и обратной матрицы.

## Реализация
- Выделение и освобождение памяти.
- Сложение, вычитание, умножение и транспонирование.
- Определитель, алгебраические дополнения, обратная матрица, тесты.

Исходники — в [`src/`](src/).

## Сборка и тесты
```bash
cd src
make
make test
```

Тесты входят в проект, но результат их запуска для этой версии не проверялся.

Учебная работа School 21. Описание задания пересказано своими словами.

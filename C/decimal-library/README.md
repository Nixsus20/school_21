# s21_decimal

Библиотека десятичной арифметики на C.

## Задача
Реализовать тип decimal с битовым представлением числа: арифметику, сравнения, конвертацию типов и округление.

## Реализация
- Работа с битами, знаком и масштабом числа.
- Арифметические операции, сравнения и преобразования типов.
- Unit-тесты на базе Check.

Исходники — в [`src/`](src/).

## Сборка и тесты
```bash
cd src
make s21_decimal.a
# тесты: make test
```

Тесты входят в проект, но результат их запуска для этой версии не проверялся.
